# TinySniff

Tool for WiFi and NFC pentest attacks powered by ESP8266. 

## Overview

TinySniff is a device designed to test the security of Wi-Fi and access control systems. It consists of an ESP8266-based device with an OLED screen, a control button, and a PN532 module.
